# 07 — 交付跨设备实时状态

**What to build:** 让 Owner 在 WebUI 同时看到 Windows 与 Android 的最新当前状态和在线性，同时确保心跳只是可过期投影，不会污染历史统计。

**Blocked by:** 02 — 建立可执行契约基础; 04 — 交付分级凭据管理.

**Status:** ready-for-agent

- [ ] 心跳契约包含设备、采集时间、当前类型和最小结构化上下文，并执行 Device Token 限制。
- [ ] Windows 与 Android 能使用现有生命周期机制发送或排队心跳。
- [ ] WebUI 并列展示所有设备状态，不推断唯一全局注意力焦点。
- [ ] 正常报告时状态年龄不超过三十秒，停止心跳后六十秒内显示离线。
- [ ] 重复或乱序心跳不会让设备状态倒退。
- [ ] 心跳数据不生成历史活动事件，也不参与任意使用时长汇总。
- [ ] HTTP 集成测试使用可控时间验证并发设备、乱序更新和自动过期。
