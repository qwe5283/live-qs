# 14 — 接入微信支付结构化事件

**What to build:** 让 Android 从微信支付通知中提取最小结构化交易事实，可靠上传并形成可修正消费摘要，同时确保通知原文永不离开设备。

**Blocked by:** 04 — 交付分级凭据管理; 05 — 打通 Windows 活动纵向链路.

**Status:** ready-for-agent

- [ ] 交易 Schema 定义金额、币种、收支方向、批准商户标签、类别、发生时间和来源标识。
- [ ] 通知正文、标题和其他自由文本不会出现在上传请求、服务端事件或日志中。
- [ ] 客户端为同一来源交易生成稳定事件标识，重复通知和重试不会重复记账。
- [ ] 无法解析的通知进入本地可诊断失败队列，不提交猜测金额。
- [ ] 缺少稳定来源标识且疑似重复的交易被标记待确认，而不是仅凭金额与时间合并。
- [ ] WebUI 展示消费总额、收支、分类和商户，并允许使用 Owner 修正流程。
- [ ] 金额和来源记录数可与选定真实样本对账，敏感读取受 Query scope 限制。
