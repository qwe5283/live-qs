# 08 — 交付时区与双时间指标

**What to build:** 让 Owner 以稳定报表时区查看活动，并明确区分所有设备相加的使用时间与跨设备去重后的实际活跃覆盖时间。

**Blocked by:** 05 — 打通 Windows 活动纵向链路.

**Status:** ready-for-agent

- [ ] 事件事实以 UTC 保存，同时保留采集 IANA 时区和当时 offset。
- [ ] Owner 能配置默认报表时区，WebUI 不因浏览器所在时区改变同一日报。
- [ ] 日与周查询按请求或 Owner 默认时区划分，缓存身份包含时区。
- [ ] `device_minutes` 对符合条件的设备区间求和，允许超过自然经过时间。
- [ ] `active_minutes` 对非 AFK 区间求并集，重叠时间只计算一次。
- [ ] 时间线保留并发设备轨道，摘要和 API 明确标注两种指标。
- [ ] 自动化测试覆盖跨午夜、重叠、相邻、空区间和夏令时边界。
