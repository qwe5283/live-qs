# 11 — 交付可审计人工修正

**What to build:** 让 Owner 修正自动提取或分类结果、标记误报并立即获得正确摘要，同时完整保留采集来源和修改历史。

**Blocked by:** 03 — 交付局域网 Owner 登录; 05 — 打通 Windows 活动纵向链路.

**Status:** ready-for-agent

- [ ] WebUI 允许对契约批准的结构化字段进行修正，并可记录可选原因。
- [ ] 修正使用同一事件标识和更高 revision，保留原始结构化观测及来源。
- [ ] Owner 能将误报标记为无效，使其不再进入时间线默认视图和统计。
- [ ] 默认查询返回最新有效解释，并标明自动或人工、是否 corrected。
- [ ] 关键金额、时间或分类修正会重建受影响的派生摘要。
- [ ] 审计记录显示 actor、时间、变更字段和原因，但不包含凭据或禁止上传的原始文本。
- [ ] 未认证、Device Token 和 Query Token 均无法执行修正。
