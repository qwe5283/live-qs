# 06 — 交付同步诊断与失败队列

**What to build:** 让 Owner 能判断数据缺失是没有活动、尚未上传还是同步失败，并让客户端在断网和进程重启后继续可靠交付。

**Blocked by:** 05 — 打通 Windows 活动纵向链路.

**Status:** ready-for-agent

- [ ] WebUI 显示每台设备最后采集、最后成功上传、待上传数量和最近错误。
- [ ] 瞬时网络或服务端错误使用带抖动的指数退避，恢复后自动继续。
- [ ] Schema 非法、scope 不足等永久失败进入可查看失败队列，不再无限重试。
- [ ] 失败项显示稳定错误码和安全摘要，不泄露 Token 或本地原始敏感文本。
- [ ] 客户端进程退出并重启后，未确认 outbox 和失败队列状态保持一致。
- [ ] 自动化状态机测试覆盖成功、断网、部分确认、永久拒绝、stale revision 和重启。
- [ ] 人工模拟断网后恢复，Owner 无需修改数据库即可观察队列逐步清空。
