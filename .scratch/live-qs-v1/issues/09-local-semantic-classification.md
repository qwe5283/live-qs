# 09 — 交付本地语义分类

**What to build:** 让 Owner 在 WebUI 定义跨平台服务和项目语义，由 Windows 在本地使用标题规则分类并只上传可解释标签，使浏览器与原生应用可以按同一 subject 汇总。

**Blocked by:** 04 — 交付分级凭据管理; 05 — 打通 Windows 活动纵向链路.

**Status:** ready-for-agent

- [ ] Owner 能管理语义实体、应用或包名规则、标题关键词或正则、优先级和规则版本。
- [ ] Device Token 只能读取适用规则；客户端缓存最后成功版本并可离线执行。
- [ ] Windows 在本地匹配原始标题，上传结果只包含 subject、类别、规则标识、版本和置信度。
- [ ] 未获批准的项目名称不会作为云端标签上传，而以不透明标识表示。
- [ ] Edge 中命中哔哩哔哩的活动可与 Android 包名映射到同一服务 subject，同时保留应用和设备来源。
- [ ] Rider 可按批准别名区分项目，原始项目标题仍留在本地。
- [ ] 如需上传标题指纹，必须使用设备秘密 HMAC；普通未加盐摘要不满足要求。
- [ ] 黄金样例测试覆盖规则优先级、无匹配、冲突、版本和跨平台映射。
