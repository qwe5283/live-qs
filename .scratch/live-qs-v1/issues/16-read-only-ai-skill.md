# 16 — 交付只读 AI Skill

**What to build:** 让获得受限 Query Token 的 AI Agent 查询当前上下文、时间摘要和数据覆盖，并生成带证据的分析建议，同时在协议上完全没有修改或执行能力。

**Blocked by:** 04 — 交付分级凭据管理; 08 — 交付时区与双时间指标; 11 — 交付可审计人工修正; 15 — 交付来源优先级与覆盖度.

**Status:** ready-for-agent

- [ ] Skill 只包装公开 OpenAPI 查询能力，不复制统计或来源选择逻辑。
- [ ] Query Token 可分别限制活动、健康、消费和当前上下文读取。
- [ ] 每次查询必须有受限时间范围、分页、速率限制、到期和撤销行为。
- [ ] 响应包含报表时区、时间范围、来源、覆盖度、冲突和 corrected 状态。
- [ ] AI credential 无法访问事件写入、修正、规则、凭据、删除或管理操作。
- [ ] 审计记录访问主体、scope、时间范围、数据类型和结果数量，但不保存提示词正文。
- [ ] 使用缺失和冲突样例验证 Skill 不会把不完整数据表达成确定事实。
